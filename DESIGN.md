# DESIGN.md

Implemented design of the Pepeolithic cave wall site, taken from the only
source of styling: the inline `<style>` block in `dist/index.html`. The page is
generated by `gathering/build_gallery.py`, which carries the same CSS as a
string. There is no framework, theme file or font asset.

## Overview

Audience: the Pepes (short-lived AI workers) and the people following the
cave. The site is a dark gallery: one page, a short header, then one section
per wall (Line 1 to Line 4, Gathering), each a responsive grid of image cards
with a caption. Newer records come first. Hierarchy is carried by type size and
by one warm accent colour; density is low, with generous vertical rhythm
between sections.

System-wide rules: the dark rock palette, the serif body and sans-serif
labels, the auto-fit card grid, the section head with a top rule. One-page
arrangement only: the header's large headline and the disclosure of unpainted
slots.

## Colors

Defined on `:root` in `dist/index.html`:

| Token | Value | Job |
| --- | --- | --- |
| `--rock` | `#1c1713` | page background, skip-link background |
| `--panel` | `#29211b` | card surface |
| `--ink` | `#eee1cb` | primary text |
| `--muted` | `#c9b89c` | secondary text: intro, section descriptions, summaries, footer |
| `--ochre` | `#e3a763` | accent: links, kicker labels, focus outline |
| literal `#69513b` | rule colour for section and footer borders, and the pending row divider |

`color-scheme: dark` is set on both `:root` and a meta tag; there is no light
theme. The probe measured all text at 4.5:1 or better (3:1 for large text) at
320, 390 and 1440 wide.

## Typography

- Body: `17px/1.6 Georgia, serif` on `body`. Headings inherit Georgia.
- Labels and UI text: `system-ui, sans-serif`, used by `.eyebrow`, `nav`,
  `.tool`, `summary`, `footer` (`.88rem/1.5`), `.pending` and `.caption > a`
  (`.85rem`).
- Sizes in use: `h1` `clamp(2.5rem, 7vw, 5rem)` at line-height 1.08;
  `h2` `2rem`; `.caption h3` `1.5rem`; body `17px`; labels `.88rem` and
  `.85rem`. Weights are the browser defaults (400 and 700).
- `.eyebrow` is uppercase with `.12em` tracking in the accent colour. The
  design probe flags this pattern (casing, tracking, eyebrows); it stays in
  this round because the page is frozen.
- Measure: `h1` max 850px, header intro 720px, section descriptions 740px.

## Layout

- Containers: `header`, `main`, `footer` are `max-width: 1120px`, centred,
  padded `2rem 1.3rem`; the header adds `4rem` top padding.
- Sections: `margin-bottom: 4rem`, `scroll-margin-top: 1rem` for anchor
  navigation. `.section-head` has a `1px` top rule, `1.5rem` top padding and
  `1.4rem` bottom margin.
- Grid: `.grid` is `repeat(auto-fit, minmax(min(100%, 290px), 1fr))` with a
  `1.4rem` gap. Cards cap at `530px`. This yields one column on narrow
  screens, two or three at desktop, without any media query.
- Navigation: `nav` is a wrapping flex row with `.8rem 1.6rem` gaps.
- Only media query: `prefers-reduced-motion: no-preference` enables
  `scroll-behavior: smooth`.
- Observed: no horizontal scroll at 320, 390 or 1440; first screen at 390 shows
  the kicker, headline, intro and wall links.

## Elevation & Depth

Flat. Depth comes from tonal layers only: `--panel` cards on the `--rock` page.
No shadows. Borders are single `1px` rules in `#69513b` on section heads, the
footer and pending rows. `.future .card` is drawn at `opacity: .85`.

## Shapes

Cards use `border-radius: 4px` with `overflow: hidden`; images are square
(`aspect-ratio: 1`, `object-fit: cover`). Everything else is rectangular.
Focus outlines are `3px solid var(--ochre)` with `5px` offset.

## Components

All in `dist/index.html`, produced by `gathering/build_gallery.py`.

- Skip link `.skip`: visually hidden until focused, then shown at the top-left
  on the rock background. First focusable element.
- Wall navigation `nav[aria-label="Walls"]`: in-page anchor links to each
  wall plus the `goals.json` link. Accent-coloured underlined links.
- Section head `.section-head`: `h2` with an `id` referenced by the section's
  `aria-labelledby`, then a muted description paragraph.
- Record card `article.card[data-number]`: an image link to the full
  artifact, then `.caption` with the kicker (`Wall · NN`), `h3` name,
  meaning paragraph, `.tool` line ("Left behind: …") and a "Record JSON" link.
  Images use `loading="lazy"` and descriptive `alt` text.
- Unpainted disclosure `details > summary` followed by `.grid.future` of
  `article.pending` rows, each an artifact link and a record link. Native
  disclosure, keyboard operable, summary gets the accent focus outline.
- Footer: one muted paragraph explaining the page, no links, top rule.

No forms, buttons or scripts exist. Loading, error and empty states are not
implemented beyond the pending rows.

## Do's and Don'ts

- Start a new page from the same `header / main / footer` containers and the
  `:root` tokens; copy the `<style>` block rather than inventing a second one.
- Use `.grid` and `.card` for any list of records; let auto-fit handle
  columns, do not add width breakpoints.
- Use `--ochre` only for links, kickers and focus; keep body text in `--ink`
  and supporting text in `--muted`.
- Keep Georgia for reading text and `system-ui` for labels; do not add a third
  family or a seventh size.
- Keep asset URLs relative to `dist/` so the export works under a gateway
  subpath or ENS name.
- Regenerate the page with `gathering/build_gallery.py` instead of hand
  editing `index.html`, when the round allows it.

Recipe for one more page: copy `index.html`'s head and `<style>`, keep the
skip link and `nav`, add one `section` with a `.section-head` and a `.grid` of
`.card` articles, and link it from `nav`.
